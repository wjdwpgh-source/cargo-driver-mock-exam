## 풀이·채점 방식 변경 (2026-10-19, PRD v1.9)

요청: "제출하기 버튼 기능은 삭제하고, 한 문제씩 풀 때마다 정답·오답과 해설을 보여 달라"

| 구분 | 변경 전 (S2) | 변경 후 |
|---|---|---|
| 채점 시점 | 제출 시 한꺼번에 | **답을 고르는 즉시 문항별 채점** |
| 정답·해설 | 풀이 중 비공개 | 답하면 바로 정답/오답, 정답 번호, 해설, 관련 법령 표시 |
| 답 변경 | 제출 전까지 자유롭게 변경·해제 | 고른 답은 고정(변경 불가) |
| 제출하기 버튼 | 상단·번호판·마지막 문항에 있음 | **삭제** |
| 시험 종료 | 제출 버튼 / 시간 종료 | 80문항을 모두 풀면 "결과 보기" / 시간 종료 시 자동 종료 |
| 진행 현황 | 응답 수 | 정답 수 · 오답 수 · 남은 문항 수 |
| 번호판 | 응답/미응답 | 정답(초록)/오답(빨강)/안 푼 문항, "안 푼 문항으로" 이동 |
| 마지막 문항 버튼 | 제출 → | 안 푼 문항이 있으면 "안 푼 문항으로", 모두 풀었으면 "결과 보기" |
| 키보드 | 1~4 선택, ←/→ 이동 | 같음 + 답한 뒤 Enter로 다음 문항 |

- 최종 점수 계산(정답 수 × 1.25점, 60점 이상 합격)과 저장 형식은 그대로라 기존 기록과 호환됨
- 진행 중이던 이전 방식의 시험도 그대로 이어 풀 수 있음(이미 고른 답은 채점된 상태로 표시)

### 테스트 결과
- 단위 테스트 18건 통과 (답 고정·문항별 판정·집계 테스트 추가)

- **남은 시간**: 창을 닫아 둔 동안은 시간이 흐르지 않음. 닫을 때의 남은 시간부터 다시 시작
