# 베타 테스트 안내 (PRD 10.4)

화물운송종사자격시험을 준비하는 분 5~10명에게 공개 전 주소를 먼저 알려 드리고 의견을 받습니다.
베타 테스트는 **7단계 GitHub Pages 배포 후**(보안 주소 https가 생긴 뒤) 진행합니다.

## 1. 참가자에게 보낼 안내문 (복사해서 사용)

> 안녕하세요. 화물운송종사자격시험 무료 모의시험 프로그램을 공개 전에 먼저 써 보실 분을 찾고 있습니다.
>
> - 주소: (배포 주소)
> - 가입 없이 닉네임만 입력하면 됩니다. 기록은 내 휴대폰·PC 브라우저에만 저장되고 어디에도 전송되지 않습니다.
> - 기간: (시작일) ~ (종료일), 1주일 정도
> - 부탁드리는 것: 실전 모의시험 1회 이상, 틀린 문제 복습 1회 이상
>
> 이런 점을 알려 주세요.
> 1. 정답이 틀렸거나 해설이 이상한 문제 – 화면에 보이는 **문제 번호(예: LAW-0012)**와 함께
> 2. 이해하기 어려운 해설이나 힌트
> 3. 불편하거나 글자가 잘 안 보이는 화면
> 4. 멈춤·오류 등 이상한 동작 – 어떤 화면에서 무엇을 눌렀는지, 사용한 기기(예: 갤럭시 S23, 삼성 인터넷)
>
> 해설 아래 **'오류 신고'** 버튼을 누르면 문제 번호가 자동으로 들어간 신고 화면이 열립니다. (GitHub 계정이 없으면 이 메시지에 답장으로 보내 주셔도 됩니다.)

## 2. 의견 받는 방법

| 방법 | 설명 |
|---|---|
| 오류 신고 버튼 | 해설·결과 다시보기의 '오류 신고' → GitHub Issue 작성 화면(문제 ID·버전·지문 자동 입력). `data/config.json`의 `issue_url`에 저장소 주소를 넣으면 켜집니다 |
| 메시지·이메일 | GitHub 계정이 없는 참가자용. 운영자가 받은 내용을 Issue로 옮겨 적습니다 |

Issue 제목 머리말: `[문제]` 정답·해설 오류 · `[화면]` 불편한 화면 · `[오류]` 오작동 · `[제안]` 기타 의견

## 3. 처리 기준

| 분류 | 예 | 공개 전 처리 |
|---|---|---|
| 오류(필수) | 정답 오류, 기록 사라짐, 화면 멈춤, 시험 진행 불가 | **반드시 해결** |
| 필수 개선 | 글자가 잘려 읽을 수 없음, 특정 기기에서 버튼이 안 눌림 | **반드시 해결** |
| 개선 | 해설이 어려움, 힌트가 너무 쉬움/어려움 | 가능하면 해결, 아니면 다음 판 |
| 제안 | 새 기능 요청 | 8단계(확장)로 넘김 |

## 4. 운영자 점검 목록

- ☐ 배포 주소에서 시험 1회 완주 확인 (PC·휴대폰)
- ☐ `issue_url` 설정 → 오류 신고 버튼 켜짐 확인
- ☐ 참가자 5~10명 모집, 안내문 발송
- ☐ 매일 Issue 확인 → 분류(오류·필수·개선·제안)
- ☐ 문제 오류는 엑셀 수정 → `문제변환.bat` → 다시 배포 (해당 문제 version이 올라가 '수정된 문제'로 표시됨)
- ☐ 종료 후 결과를 `docs/테스트보고서.md` 8장에 추가
